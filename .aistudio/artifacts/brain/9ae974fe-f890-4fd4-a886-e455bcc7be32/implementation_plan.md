## 1. Overview & Core Concept

### What It Does
Проект эволюционирует из интерактивного киберпанк-оракула и финансово-квантового симулятора в полноценную экосистему **Cyber-Occult TCG & Web3 Simulator**. Пользователь не просто открывает и осматривает Арканы, но и:
1. Формирует боевые колоды из собранных и кастомизированных карт (Cyber/Bio/Quantum/Void).
2. Сражается в тактическом дуэльном режиме против автономного «Нейро-Демиурга» (AI Bot) или локального игрока по P2P.
3. Получает ежедневные предсказания и лунные фазы прямо на домашнем экране Android через виджет Glance.
4. Создает и кастомизирует уникальные карты через генеративный ИИ (Gemini + процедурные Canvas-шейдеры).

### Target Audience & Persona
- Любители киберпанк-эстетики (Deus Ex, Cyberpunk 2077, Ghost in the Shell), интерактивных симуляторов и оккультизма.
- Игроки коллекционных карточных игр (Hearthstone, Inscryption, Gwent), ценящие атмосферный саунд-дизайн, тактильный отклик и глубокую кастомизацию.

### Key Value
Трансформация пассивного чтения карт в активный игровой цикл (Core Gameplay Loop): **Гадание -> Фарм и улучшение Арканов -> Сборка Колоды -> Тактическая Дуэль -> Крафт уникальных NFT/Шейдеров -> Прогрессия рангов**.

## 3. Key Product Decisions & Trade-Offs

1. **Игровой движок дуэлей внутри Jetpack Compose:**
   - *Решение:* Полноценный детерминированный пошаговый State-Machine движок в Kotlin Coroutines / StateFlow без тяжелых внешних движков (Unity/Godot).
   - *Почему:* Сохраняет сверхлегкий вес APK, мгновенный холодный старт (<300мс), нативную интеграцию с M3 темами и плавность Compose 120Hz.
2. **Модуляризация монолитов (`CyberTarotScreens.kt` & `TarotViewModel.kt`):**
   - *Решение:* Декомпозиция на фиче-пакеты (`feature/duel`, `feature/oracle`, `feature/market`, `feature/glance_widget`) с четкими MVI-намерениями (Intent/Reducer).
   - *Почему:* Текущие файлы превышают 1800 строк. Разделение устраняет риски регрессий и ускоряет инкрементальную сборку.
3. **Хранение данных и боевой прогрессии:**
   - *Решение:* Локальная база Room Database с версионированием и миграциями для колод, инвентаря, истории боев и достижений. Внешний бэкап через зашифрованный JSON/Swarm.
   - *Почему:* Полная автономность, нулевая задержка сети, приватность оффлайн-пользователя.

### Core Entities & Combat State Models
```kotlin
// Боевая сущность карты
data class BattleCard(
    val id: String,
    val name: String,
    val arcanaType: ArcanaType,
    val element: ElementAffinity, // CYBER, BIO, QUANTUM, VOID
    val energyCost: Int,          // 1..6 RAM
    val power: Int,               // Базовая сила атаки
    val defense: Int,             // Очки брони/щита
    val ability: CardAbility?,    // Особый кибер-эффект
    val isUpright: Boolean = true // Прямое/Перевернутое положение меняет эффект!
)

enum class ElementAffinity {
    CYBER,   // Силен против BIO, слаб против QUANTUM
    BIO,     // Силен против VOID, слаб против CYBER
    QUANTUM, // Силен против CYBER, слаб против VOID
    VOID     // Силен против QUANTUM, слаб против BIO
}

data class DuelState(
    val turnNumber: Int = 1,
    val isPlayerTurn: Boolean = true,
    val playerHp: Int = 30,
    val playerMaxHp: Int = 30,
    val playerEnergy: Int = 1,
    val playerMaxEnergy: Int = 1,
    val enemyHp: Int = 30,
    val enemyEnergy: Int = 1,
    val playerHand: List<BattleCard> = emptyList(),
    val playerBoard: List<BattleCard?> = listOf(null, null, null),
    val enemyBoard: List<BattleCard?> = listOf(null, null, null),
    val combatLog: List<String> = emptyList(),
    val winner: DuelWinner? = null
)
```

## 5. Атомизированные Спринты Эволюции

### СПРИНТ 1: Движок Карточных Дуэлей TCG («Битва Арканов»)
> **Цель:** Создать играбельный боевой режим прямо в приложении с интерактивной доской, розыгрышем карт за энергию и ИИ-противником.

- [x] **Task 1.1: Боевая математика и модели данных TCG**
  - Создать `BattleCard`, `ElementAffinity`, `CardAbility` (щит, вампиризм, перегрузка RAM, проклятие пустоты).
  - Настроить конвертер из существующих 78 карт Арканов в боевые характеристики с учетом ранга и масти.
  - Реализовать матрицу стихийного превосходства (множители x1.5 / x0.75).
- [x] **Task 1.2: Игровой движок (Turn-Based Combat State Machine)**
  - Реализовать `DuelCombatEngine`: фаза добора карт (Draw Phase), фаза энергии (+1 RAM за ход, макс 10), фаза действий (Play/Attack Phase), завершение хода.
  - Разработать эвристический ИИ (`NeuroDemiurgeAI`): оценка поля, расчет оптимального размена существ и атаки в лицо.
  - Обработка прямого и перевернутого положения карты (прямая = атака/бафф, перевернутая = контроль/дебафф соперника).
- [x] **Task 1.3: Пользовательский интерфейс Арены Дуэли (`DuelArenaScreen.kt`)**
  - Интерактивная доска 3x3 слотов с неоновой подсветкой свободных позиций.
  - Рука игрока в виде изогнутого веера карт с возможностью свайпа и драга на поле боя.
  - Анимированные индикаторы здоровья, щитов и ячеек RAM (Data Energy).
  - Журнал боевых событий (Cyber Terminal Combat Log) с выводом урона и критических ударов.
- [x] **Task 1.4: Звуковая интеграция дуэли (`CyberNoirAudioEngine`)**
  - Добавить процедурные звуковые паттерны: розыгрыш карты (synth whoosh), удар (laser clash), критический урон (sub-bass drop), победа/поражение.
- [x] **Definition of Done (DoD) Спринта 1:**
  1. Пользователь может открыть вкладку «DUEL», выбрать свою стартовую колоду и начать бой против ИИ.
  2. Все действия (выкладка карт, атака, пропуск хода) анимированы с виброоткликом и звуком.
  3. Полный цикл матча завершается экраном победы/поражения с начислением кредитов/XP и записью в статистику.
  4. Проект успешно собирается через `compile_applet` без ошибок и предупреждений.
