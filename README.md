# Weed Guru / Cyber Tarot

Футуристический киберпанк-оракул и коллекционная карточная система.

**Текущий статус:** продвинутый дизайн-прототип (Android / Kotlin + Jetpack Compose).

## Структура репозитория

- `app/` — Android-приложение (Kotlin + Jetpack Compose)
- `assets/` — ресурсы и вспомогательные фронтенд-компоненты
- `docs/` — вся проектная документация (планы, архитектура, отчёты)
- `gradle/` — конфигурация сборки

Подробнее о документации см. [docs/README.md](docs/README.md).

## Быстрый старт

Документация и актуальные планы развития находятся в папке [`docs/`](docs/).
