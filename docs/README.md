# Documentation

Структура документации проекта **WEED GURU / Cyber Tarot**.

## Папки

| Папка | Назначение |
|-------|----------|
| `architecture/` | Архитектурные решения, NFT-модули, границы слоёв и планы развития ядра |
| `compliance/` | Google Play Data Safety, Privacy Policy, возрастные и региональные дисклеймеры |
| `evolution/` | Roadmap'ы и планы эволюции продукта |
| `technical/` | Технические спецификации, гайды для разработчиков, модели безопасности и транспорта |
| `reports/` | Аудиты, статус-репорты, инвестиционные и концепт-материалы |
| `archive/` | Устаревшие или вспомогательные исторические документы |

## Правила

- Новые планы, спецификации и отчёты размещаем только в существующих тематических папках выше.
- Инвестиционные и концептуальные документы должны явно разделять реализованный локальный прототип (`Sandbox`) и будущие этапы roadmap.
- Корень репозитория держим чистым от лишней markdown-документации (кроме `README.md`).
