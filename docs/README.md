# Documentation

Структура документации проекта **Weed Guru / Cyber Tarot**.

## Папки

| Папка | Назначение |
|-------|----------|
| `architecture/` | Архитектурные решения, NFT-архитектура, планы по Rust, границы слоёв |
| `evolution/` | Roadmap'ы и планы эволюции продукта |
| `product/` | Продуктовое видение, game design, токеномика, UX |
| `technical/` | Технические спецификации, API, гайды для разработчиков |
| `reports/` | Аудиты, статус-репорты, инвестиционные материалы |
| `decisions/` | Architecture Decision Records (ADR) — зафиксированные важные решения |
| `archive/` | Устаревшие или вспомогательные документы |

## Правила

- Новые планы и отчёты кладём в соответствующую папку.
- Важные архитектурные решения оформляем как ADR в `decisions/`.
- Корень репозитория стараемся держать чистым от markdown-документации.
